# Assets

Every visual and font asset used by this concept, with its source and licence. No stock photography, no photographs of people, and no third-party images are used.

## Illustration (original artwork)

All illustrations are original vector artwork created for this concept by OFF/SHIFT Studio. They are generated by `scripts/generate-art.mjs` and converted to inline React SVG components by `scripts/svg-to-components.mjs` (run `npm run art` to regenerate both). Source SVG files in `public/art/` are kept for regeneration; the site renders them inline, not as `<img src="*.svg">`.

| File | Used for | Source | Licence |
| --- | --- | --- | --- |
| `public/art/hero.svg` | Home hero illustration | Original, generated by `scripts/generate-art.mjs` | Original work, owned by OFF/SHIFT Studio. No third-party rights. |
| `public/art/deck-before.svg` | Before/after: courtyard deck (before) | Original, generated | As above |
| `public/art/deck-after.svg` | Before/after: courtyard deck (after) | Original, generated | As above |
| `public/art/entry-before.svg` | Before/after: entry path (before) | Original, generated | As above |
| `public/art/entry-after.svg` | Before/after: entry path (after) | Original, generated | As above |
| `public/art/garden-before.svg` | Before/after: terraced garden (before) | Original, generated | As above |
| `public/art/garden-after.svg` | Before/after: terraced garden (after) | Original, generated | As above |
| `app/icon.svg` | Favicon | Original, hand-written SVG | As above |

The material swatches in the Materials section (spotted gum, limestone, granite, clay brick, gravel, steel) are drawn with CSS gradients in `app/globals.css`. They are original and need no licence.
